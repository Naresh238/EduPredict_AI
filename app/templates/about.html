ABOUT THE PROJECT

EduPredict AI

An end-to-end machine-learning portfolio project for academic grade estimation and exploratory student-risk analysis.

Dataset

The project uses the UCI Student Performance Mathematics dataset containing 395 student records.

Machine-learning workflow

  • Data inspection and preprocessing
  • Numeric and categorical feature transformation
  • Regression model comparison using cross-validation
  • Risk classification and held-out evaluation
  • Confusion matrix, ROC curve, and permutation importance
  • Flask web application for model inference

Selected models

Grade prediction: Random Forest Regressor.

Risk classification: Logistic Regression.

Responsible use

The dataset is limited in size and context. Predictions should not be used alone to grade students, deny opportunities, or make consequential educational decisions.
