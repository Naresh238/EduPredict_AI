Responsible Use and Limitations

This project uses a relatively small educational dataset. The risk label is a project convention based on G3 < 10, not a universal definition of academic risk. Model metrics are specific to the saved test split. Feature importance describes model reliance, not cause and effect. Do not use these predictions as the sole basis for decisions about real students.
